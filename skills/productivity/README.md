# Productivity

General workflow tools, not code-specific.

- **[caveman](./caveman/SKILL.md)** — Ultra-compressed communication mode. Cuts token usage ~75% by dropping filler while keeping full technical accuracy.
- **[grill-me](./grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved. Thin user-invoked wrapper around `grilling`.
- **[grilling](./grilling/SKILL.md)** — The questioning mechanics shared by `grill-me` and `grill-with-docs` (required by both): rounds over the decision frontier, a recommended answer per question (worded so "yes" accepts it), facts looked up rather than asked.
- **[write-a-skill](./write-a-skill/SKILL.md)** — Create new skills with proper structure, progressive disclosure, and bundled resources.
